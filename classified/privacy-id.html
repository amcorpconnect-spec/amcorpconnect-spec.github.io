File dan akun Anda

Classified Vaults diterbitkan oleh Akshay Meena. Akun aplikasi tidak diperlukan. File, nama, petunjuk, dan kunci brankas tetap di penyimpanan pribadi aplikasi. Kami tidak mengoperasikan server penerima pustaka ini dan tidak menyertakan SDK iklan, analitik, atau pelacakan.

Izin dan biometrik

Anda memilih file melalui pemilih sistem Apple. Akses kamera dan mikrofon diminta untuk perekaman yang Anda mulai. Izin menghapus foto hanya diminta saat memindahkan hasil impor yang sudah diverifikasi. Apple melakukan autentikasi Face ID atau Touch ID; Classified Vaults tidak menerima data wajah atau sidik jari. Izin dapat diubah di Pengaturan sistem.

Enkripsi dan file sementara

File tersimpan, nama, dan gambar mini dienkripsi. Pratinjau atau impor dapat membuat file sementara yang dapat dibaca di penyimpanan pribadi terlindungi. Aplikasi menghapus file pratinjau dan impor sementara saat dikunci, dibatalkan, atau dimulai. File tidak ditambahkan otomatis ke Foto atau ditampilkan di app File.

Cadangan dan berbagi

Cadangan dienkripsi dengan kata sandi cadangan dan hanya keluar dari aplikasi saat Anda memilih tujuan atau membagikannya. iCloud Drive dan penyedia lain menangani transfer dan penyimpanan sesuai kebijakan mereka. Salinan terbaca yang diekspor berada di luar perlindungan brankas. Cadangan yang dipulihkan mempertahankan kunci masing-masing brankas; kata sandi cadangan tidak menggantikan kredensial tersebut.

Retensi dan penghapusan

Item brankas yang dihapus tetap terenkripsi di Baru Dihapus. Setelah 30 hari, item dapat dihapus permanen secara otomatis saat brankas terlindungi dibuka. Anda dapat menghapusnya permanen lebih awal. Pustaka terenkripsi sebelumnya dapat disimpan secara lokal setelah pemulihan untuk keperluan pemulihan. Menghapus aplikasi menghapus data lokal; cadangan ekspor, salinan berbagi, dan beberapa item Rantai Kunci dapat tetap ada. Kelola salinan tersebut melalui penyedianya. Kami tidak memiliki salinan pusat untuk dipulihkan atau dihapus.

Langganan

Apple memproses langganan, pembayaran, pengembalian dana, dan pemulihan pembelian. Aplikasi memeriksa transaksi terverifikasi untuk menentukan akses. Kami tidak menerima nomor kartu pembayaran melalui aplikasi. Ketentuan privasi dan pembelian Apple berlaku. Kehilangan akses langganan tidak otomatis menghapus pustaka terenkripsi Anda.

Dukungan dan situs web

Jika Anda mengirim email ke dukungan, kami menerima alamat, pesan, dan lampiran lalu menggunakannya untuk menjawab. Jangan kirim kata sandi, rahasia pemulihan, atau file brankas pribadi. Pesan disimpan hanya selama diperlukan untuk menangani permintaan dan kewajiban yang berlaku. Anda dapat menghubungi kami untuk akses atau penghapusan korespondensi dukungan. Penyedia hosting dan email memproses trafik sesuai kebijakan mereka.

Pembaruan kebijakan

Kebijakan ini menjelaskan perilaku aplikasi saat ini dan dapat berubah pada versi mendatang. Kebijakan yang diterbitkan akan menampilkan tanggal pembaruan. Untuk pertanyaan privasi, hubungi Akshay Meena di amcorpconnect@gmail.com.
